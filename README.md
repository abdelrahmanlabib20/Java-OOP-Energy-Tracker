# Energy Tracker

A Java Object-Oriented Programming project that helps households
track appliance energy usage and calculate electricity bills.

## Features

- Add household appliances
- Track energy consumption
- Calculate electricity bills
- Validate user input
- Display energy usage records

## Technologies

- Java
- Object-Oriented Programming
- IntelliJ IDEA

## OOP Concepts Used

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Project Structure

- Appliance
- LightAppliance
- CoolingAppliance
- EnergyUsageRecord
- Household
- EnergyTrackerApp
